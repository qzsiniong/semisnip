# 使用

## 一次完整的交互

```
任意输入框  →  ;;  →  过滤 + 预览  →  回车  →  espanso 展开
```

面板浮在最前但不激活 App，目标输入框的光标位置全程不变——所以回车之后不需要「先把前台还回去」，也没有 espanso 官方搜索框那套 200ms 等待。

## 按键

| 操作 | 效果 |
|---|---|
| `;;` | 打开面板（第二个 `;` 被吞掉，第一个被回删） |
| 直接输入 | 过滤，空格分词、全部 AND |
| `↑` / `↓` | 上下选择，循环 |
| `Enter` | 交给 espanso 展开 |
| `Esc` | 关闭，并回删触发符残留 |
| `Backspace` | 删除过滤字符 |
| `Cmd` / `Ctrl` + 任意键 | 放行给系统并关闭面板，不吞系统快捷键 |

触发串不是写死的 `;;`，`snipshot config set trigger ,,` 可以换（只允许 ASCII，因为要被编译成物理键码序列）。

## 过滤与排序

- **trigger 的核心部分可省略前缀**：打 `log` 就能命中 `;;log`，打 `date` 命中 `:date`。
- **空格分词、全部 AND**：`log git` 两个词都要命中。
- **拼音可用**：标签会被索引成全拼与首字母，`rq` 能命中「日期」。
- **分档打分**：精确 `1000` > 前缀 `800~700` > 子串 `600` > 子序列 `300`，再叠加使用频率与最近使用时间。
- **使用统计**在 `usage.json`，删掉只影响排序，不影响功能。

## 预览

右侧详情区是**只读**的：`shell` / `script` 绝不执行，只显示红色告警与命令首行。`$|$` 光标标记原样保留，不会被当成变量。

完整行为见 [架构 · 预览的安全边界](architecture.md#预览的安全边界)。

## 三种唤起方式

| 来源 | 场景 |
|---|---|
| `tap` | 正常路径：CGEventTap 在任意 App 里识别到触发串 |
| `espanso` | 降级路径：没有辅助功能权限时，espanso 的 shell 变量调 `snipshot trigger` |
| `manual` | 手动：终端里 `snipshot trigger`，或点菜单栏第一项 |

三者只影响日志与降级判断，面板行为一致。

## 中文输入法

非激活面板拿不到 IME 会话，过滤走的是物理键码映射，所以**不能用输入法打中文过滤词**——中文标签靠拼音索引弥补。另外中文输入法下 `；；` 是全角，和 ASCII `;;` 不是同一个字符串，实测可能残留全角触发符，触发时切到英文输入法最稳。细节见 [故障排查 · 已知限制](troubleshooting.md#已知限制)。
