# 使用

## 一次完整的交互

```
任意输入框  →  ;;  →  过滤 + 预览  →  回车  →  espanso 展开
```

面板浮在最前但不激活 App，目标输入框的光标位置全程不变——所以回车之后不需要「先把前台还回去」，也没有 espanso 官方搜索框那套 200ms 等待。

## 按键

| 操作 | 效果 |
|---|---|
| `;;` | 打开面板（两个分号都照常落进文档，不吞任何键） |
| 直接输入 | 过滤，空格分词、全部 AND |
| `↑` / `↓` | 上下选择，循环 |
| `Enter` | 交给 espanso 展开（此时才把触发词从文档里清掉） |
| `Esc` | 关闭面板；`;;` 本来就在文档里，原样留着，可以接着打字 |
| 点面板外面 | 关闭，点哪儿就是哪儿（点击照常落到那个窗口上） |
| 点右上角 `✕` | 关闭，不需要键盘 |
| 菜单栏第一项 | 面板开着时变成「关闭片段面板」，同样不需要键盘 |
| 菜单栏「暂停触发 `;;`」 | 总开关：暂停后 `;;` 不弹面板（分号照常进文档），图标变成划掉样式；espanso 的降级触发仍然可用 |
| `Backspace` | 删除过滤字符；过滤串已空时再按一次 = 关闭面板 |
| `Cmd` / `Ctrl` + 任意键 | 放行给系统并关闭面板，不吞系统快捷键 |

**关闭 = 当作没触发过，而且是字面意义上的**：触发键一个都不吞（见 [架构](architecture.md#触发与焦点)），文档从面板出现那一刻起就是用户打的原样——`;;` 一直在，光标一直在它后面。按 `Esc`、点 `✕`、从菜单栏关闭、点面板外、或者退格退到空再按一次，都只是把面板收起来，一个合成按键都不发。要删掉 `;;` 就自己按两次退格。

只有确认（`Enter`）才会清掉触发词：espanso 展开时需要干净的光标位置，见 [架构](architecture.md#回传顺序)。

所有关闭路径都是同一个动作（放开吞键 → 删窗口），没有分叉。既留键盘也留鼠标，是因为面板是**非激活**的：它自己不处理键盘，`Esc` 全靠全局 tap 转发——tap 没装上（缺「辅助功能」权限、或重签之后授权失效）时，只有 `✕` 和菜单栏两项还能用（点外部同样是 tap 在听，会一起失效）。这个场景见 [故障排查](troubleshooting.md)。

触发串不是写死的 `;;`，`semisnip config set trigger ::` 可以换（只允许 ASCII，因为要被编译成物理键码序列）。注意 espanso 的降级触发串会比它多打一个末字符（`;;` → `;;;`，`::` → `:::`），见 [安装](install.md)。

## 面板内模式

面板打开后，几个标点键会切换视图。`,`、`/` 只在**查询为空**时才是命令，避免代码片段里的路径被截胡；`;` 任何查询下都进管理，`?` 在任何视图都能打开速查覆盖层：

| 按键 | 模式 | 说明 |
|---|---|---|
| `,` | 关键字视图 | 看当前片段的全部触发词、别名、来源与用量；`direct_window_ms` 内再按一次 `,` 切到 `,,` 直达 |
| `;` | 片段管理 | 带着当前选中项进管理（任何查询下都生效） |
| `/` | 命令菜单 | 重载索引 / 显示停用 / 打开管理 / 打开设置 / 快捷键速查 |
| `?` | 速查覆盖层 | 叠在当前视图上显示键位表；再按 `?` 或 `Esc` 关闭，原来的视图与选择原样还在 |
| `'` | 全文模式 | 打开后正文也参与匹配（最低档，默认关闭）；再按一次关闭 |
| `:` | 标签建议 | 查询里输入冒号，弹出已有标签候选；`↑↓` 选、`↵` 确认、`esc` 关闭；冒号必须在词首（空格或查询开头） |

管理面板里的键：`Space` 多选、`a` 全选、`d` 启停、`f` 循环来源文件、`e` 导出、`t` 加标签、`m` 迁移预览、`Enter` 打开关键字视图、`Esc` 返回查询（查询与选中项都保留）。迁移预览里 `Space` 勾选、`a` 全选可迁移项、`Enter` 应用。标签输入态里，空格分隔多个标签，`Enter` 应用，`Esc` 取消。

管理面板会显示每条片段的「毕业进度」（本周 `direct / (panel + direct)`），顶部则是整体毕业率。标签写回只改 `label` 字段、追加在尾部并去重，写入前同样备份；标签本身只允许 ASCII 字母、数字、`-`、`_`（面板没法输入中文）。

停用状态写在 `~/Library/Application Support/semisnip/library.json`，**不改动你的 espanso YAML**；搜索与直达列表都会跳过停用项。迁移则是**追加**：给 `:sig` 加一条 `,,sig`，旧触发词保留，写入前自动备份到 `backups/`（YAML 注释会丢，所以先看预览）。

## `,,` 直达

`direct_prefix`（默认 `,` `,`）是 **espanso 的原生触发前缀**，不是 semisnip 的触发串。面板关闭时 semisnip 对 `,,` 完全透明：你直接打 `,,sig`，espanso 自己展开，不开面板。

面板做的事只有两件：

- 候选行与关键字视图会标出该片段的直达触发词，能记起来就直接用；
- 从面板回车展开一条**有直达触发词**的片段后，光标附近会浮出一行「下次可直接输入 ,,xxx」，默认 3 秒自动消失（`hint_ms` 可改，设为 `0` 不弹）。

`direct_prefix` 与 `trigger` 不允许相等或互为前缀：否则 tap 会在第一个逗号就把面板叫出来，把 `,,` 抢走。配置层（`semisnip config set` 与设置窗口）都会拦下这种组合。

管理面板顶部的「本周毕业率」是**估算**：tap 在面板关闭时维护最近输入的字符缓冲，后缀命中已知直达触发词就记一次 `direct`；面板回车记 `panel`。所以「打了 `,,sig` 但没真的展开」也会算一次。密码框、安全输入、tap 未授权时天然统计不到，不必当成 bug。

## 位置

面板**跟着输入光标走**，不是"主显示器居中"——多屏时主屏常常不是用户正在打字的那块。

`position` 有两档（设置页 → 外观 → 位置，或 `semisnip config set position center`）：

| 取值 | 效果 |
|---|---|
| `auto`（默认） | 贴着插入点下方弹出，水平居中于该屏；下方空间不够就自动翻到插入点上方 |
| `center` | 当前屏幕可视区的正中 |

两种模式都按「**我在哪块屏**」选屏，只是判断依据不同：`auto` 看插入点，`center` 看当前激活窗口的中心（拿不到窗口才退到鼠标）。所以「居中」不等于「主屏居中」；光标在副屏上，面板就出现在副屏正中。

插入点是怎么问出来的：辅助功能（AX）的 `AXSelectedTextRange` → `AXBoundsForRange`。拿不到时依次退到「单行输入控件边界」→「鼠标位置」，日志里会写明这次信的是谁：

```
面板已打开 720x420 @ (540,526)（全局）· 跟随插入点（AX 插入点）· 屏 1 1800x1169 @ (0,0) · 本地 (540,526)
```

终端、部分 Electron 应用不暴露插入点，这时贴的就是鼠标——位置略差一点，但不会不出现。

## 过滤与排序

- **trigger 的核心部分可省略前缀**：打 `log` 就能命中 `;;log`，打 `date` 命中 `:date`。
- **严格字符集**：只收小写字母、数字、空格、冒号，其余字符自动丢弃；解析条会实时标出哪些字符被忽略。大写自动转小写。
- **空格分词、全部 AND**：`log git` 两个词都要命中。
- **标签过滤**：`:dev` 只留下带 `dev` 标签的片段；`:bd` 也能用拼音首字母命中中文标签「表单」。
- **拼音可用**：标题会被索引成全拼与首字母，`rq` 能命中「日期」。
- **分档打分**：trigger 精确 `1000` > 前缀 `800~700` > 子串 `600` > 拼写容错 `500` > 子序列 `300`；`search_terms` 独立成档（`900 / 650~750 / 530`），只低于 trigger；标题打 8 折，拼音 `520~380`；正文只在全文模式下参与，且是 `200 / 170 / 120` 的最低档。
- **精确触发词无条件置顶**：查询与某个 trigger（或去掉前缀后的核心）完全相等时，这条永远排第一。
- **使用统计**在 `usage.json`，删掉只影响排序，不影响功能；频次加成只看近 30 天的使用量。

## 预览

右侧详情区是**只读**的：`shell` / `script` 绝不执行，只显示红色告警与命令首行。`$|$` 光标标记原样保留，不会被当成变量。

完整行为见 [架构 · 预览的安全边界](architecture.md#预览的安全边界)。

## 三种唤起方式

| 来源 | 场景 |
|---|---|
| `tap` | 正常路径：CGEventTap 在任意 App 里识别到触发串 |
| `espanso` | 降级路径：没有辅助功能权限时，espanso 的 shell 变量调 `semisnip trigger` |
| `manual` | 手动：终端里 `semisnip trigger`，或点菜单栏第一项 |

三者只影响日志与降级判断，面板行为一致。

区别只有一个：走 `espanso` 那条说明 `tap` 没装上，面板收不到任何按键，所以它会换成「需要授权」页。那一页除授权说明外还保留一列**鼠标可点**的候选：点一下直接走 espanso 求值展开，这是没有键盘时唯一能把片段送出去的路径；按钮是「打开辅助功能设置 / 重新检查 / 稍后」，授权到位后几秒内自动切回搜索列表。

## 中文输入法

非激活面板拿不到 IME 会话，过滤走的是物理键码映射，所以**不能用输入法打中文过滤词**——中文标签靠拼音索引弥补。另外中文输入法下 `；；` 是全角，和 ASCII `;;` 不是同一个字符串，实测可能残留全角触发符，触发时切到英文输入法最稳。细节见 [故障排查 · 已知限制](troubleshooting.md#已知限制)。
