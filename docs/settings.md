# 设置与首次引导

daemon 不进 Dock，平时只有菜单栏一个图标。真正需要"停留一会儿操作"的地方只有两个窗口：

| 窗口 | 类型 | 谁打开 | 抢焦点 |
|---|---|---|---|
| 偏好设置 | `WindowKind::Normal` + 原生标题栏 | 菜单栏 →「偏好设置…」 | 是 |
| 首次引导 | 同上，固定尺寸 | 第一次启动、菜单栏 →「使用引导…」 | 是 |

它们和面板是反的：面板是 `PopUp` + 非激活，**不抢焦点**才能做到回车后不用还原前台；这两个窗口是用户特意来操作的，抢焦点才符合直觉。

实现分别在 `src/ui/settings.rs` 与 `src/ui/onboarding.rs`，共用 `src/ui/mod.rs` 里的主题同步与 `reveal()`。

## 偏好设置

四个页签：

| 页签 | 内容 |
|---|---|
| 通用 | 触发键、触发键间隔、候选条数、焦点模式 |
| 外观 | 面板位置（自动 / 居中）、面板宽高、显示详情栏、预览剪贴板内容 |
| 行为 | 回传前等待、粘贴兜底 |
| 关于 | 版本、三个路径、打开配置 / 打开日志 / 重建索引 / 重新看引导 |

### 改动立即生效，没有"保存"

每次改动都会走同一条链路：

```
输入 → SettingsState::commit
        ├─ validate() 不过 → 只改内存，底部红字说明原因，**不落盘**
        └─ 通过 → config.save()（原子写：.yml.tmp → rename）
                  → 投 Event::ConfigChanged
                  → scheduler → AppState::reload_config
                  → tap::set_trigger（触发键换键码）
```

面板尺寸、`position`、`show_detail` 这类**不用通知**：面板窗口每次打开都是新建的，`ui::window::open` 会重新读配置。

校验规则（`SettingsState::validate`）：触发键 1–4 个 ASCII 字符、宽度 ≥ 360、高度 ≥ 240、候选条数 ≥ 1。schema 里也有一份同样的约束，但那是给**手改 YAML 的编辑器**看的；设置窗口直接改结构体，不经过 serde，所以必须再校验一次。

每页右上角的「重置」只重置**当前页**的字段，同样走上面那条链路落盘。

### 手改文件和设置窗口的区别

| 改法 | 何时生效 |
|---|---|
| 设置窗口 | 立即（投事件） |
| `semisnip config set` | 下次启动 |
| 直接编辑 `config.yml` | 下次启动 |

没有文件 watcher：手改之后要 `launchctl kickstart -k gui/$(id -u)/com.semisnip.daemon`。设置窗口也不监听磁盘——开着窗口时在终端里改了别的字段，重开窗口才看得到。

### 改触发键之后还要做一件事

`trigger` 同时写在 espanso 的降级定义里（`match/semisnip.yml`，tap 不可用时靠它唤醒面板）。设置窗口只改配置，不会去动 espanso 的文件——重新生成要跑一次：

```bash
semisnip install     # 重写 match 文件，然后 espanso restart
```

字段说明里也写了这一条。

## 首次引导

触发条件只有一个：配置里 `onboarded` 还是 `false`。第一次启动时配置文件通常还不存在，`Config::default()` 给的就是 `false`。

四步，照用户的心路排，不是照功能排：

1. **欢迎**：标记 + 一句话说清「敲 `;;`，挑一条，交给 espanso」；卡片里能直接跳去设置改触发键。
2. **先确认环境**：三行体检——espanso 版本、辅助功能、片段库条数。缺辅助功能就给「去授权」（直接打开系统设置的辅助功能页）；tap 没装上时「继续」降级成次要按钮，别让人一路点过去。
3. **三步取一条片段**：敲触发键 → 输入关键词（附拼音提示）→ 回车，配键盘帽。
4. **一切就绪**：写 `onboarded: true` 并关窗。

### 体检是快照，不是实时

三项结果在**打开窗口那一刻**算一次（点「重新检查」再算一次）。`espanso --version` 要起子进程，每帧算一次窗口会卡。授权发生在窗口外面，所以第 2 步下面专门放了「重新检查」——用户勾完权限回来点一下，绿了再继续。

### 关掉窗口 ≠ 看完了

没走到最后一步就不会写 `onboarded`，下次启动会再弹。这是刻意的：比"关一次就永远看不到"更符合"我还没看懂，下次再说"。

菜单栏 →「使用引导…」会**先把 `onboarded` 置回 `false` 再开窗**：即使用户中途关掉，下次启动还会再弹，不会漏。要彻底关掉这个行为，把 `onboarded` 设成 `true`：

```bash
semisnip config set onboarded true
```

### 结算页不自动开面板

面板是给"正在某个输入框里打字"的人准备的。刚从引导窗口出来的人没有那个上下文，弹出来只会莫名其妙。想试就自己去任意输入框敲 `;;`。

## 已知取舍

- **主题只在开窗时同步一次**：`ui::sync_theme` 读系统外观设成 Light/Dark，窗口开着时切换系统外观不会实时变。
- **引导窗固定 560×640，不可缩放**：版式是按这个尺寸排的，拉宽只会让行长变得难读。
- **设置窗口只有一个**：再点菜单只是把已有窗口提到最前；用户关掉之后句柄失效，才新建。
